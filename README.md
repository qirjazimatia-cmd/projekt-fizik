# Don Bosko Connect · ScienceQuest

Aplikacion SwiftUI (iOS, iPadOS, macOS) + Supabase për shkollën Don Bosko. ScienceQuest (mësime dhe laboratorë) është pjesë e tij.

- Fillo këtu: `START-HERE.md`, konfigurimi i Supabase: `SUPABASE-SETUP.md`
- Kërkesat e produktit: `PROMPT-DON-BOSKO.md`
- Rregullat e punës për dy persona (Matia, Juri) me Claude: `CLAUDE.md`
- Detyrat: GitHub Issues (etiketat `matia`, `juri`, `në-punë`, `supabase`)

## Si ta hapësh në Xcode
1. Xcode → **Clone Git Repository…** → `https://github.com/qirjazimatia-cmd/projekt-fizik`
2. Hap `ScienceQuest.xcodeproj` → ⌘B.
3. Para çdo pune: **Source Control → Pull**.
